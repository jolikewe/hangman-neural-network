Every move runs these five steps, live, with the same weights as the game above. Type any pattern below, using _ for hidden letters, to see what the network makes of it.

Mask

Letters already guessed stay visible. Every other position is hidden.

One-hot

Each position becomes 26 slots with a single one. Hidden positions are all zeros.

BiGRU

A 16-dim embedding feeds two GRU layers, one reading left to right, one right to left, 128 units each.

Per-position odds

Softmax over 26 letters at every hidden slot. Tried letters are zeroed and each slot is renormalised.

Best pick

The single highest cell across all positions and letters is the guess.
